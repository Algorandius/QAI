用「一键连接」前，先按顺序做三步：①NapCat 里扫码登录 → ②手动关掉 NapCat 的命令行窗口 → ③回来点「一键连接」。窗口还开着时 NapCat 退出会把刚写好的配置覆盖回去，连接就会一直失败。
