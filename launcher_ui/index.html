从 GitHub 下载最新 Windows Node 包，约 120MB；安装后仍需扫码登录 QQ。
🔒 QAI 是本地前端：API Key 只写入本机 `.env`，请求由本机直接发送到模型厂商； QAI 没有中转服务器，不会上传、收集或泄露你的 Key。
